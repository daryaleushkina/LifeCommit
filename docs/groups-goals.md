# Общая цель в группе: что копим и как это узнаём

Решения владелицы 01.10.2026 (круги 16–18 на холсте дизайна). Плитка в «Кто делает» называется **«Общая цель»** (подпись «вместе до одной цифры»), не «копилка»: копят не только деньги.

## Принципы

- Человек вводит только **название и число** («Отпуск в Грузии», 150 000). Единицу никто не выбирает из списка.
- Что это за цифра, узнаём сами и показываем подписью **«будем считать в рублях · поменять»**. Не узнали — ничего не пишем, цель живёт как «27 из 40».
- **Валюту не угадываем и не спрашиваем.** Названа в голосе или тексте («долларов», «$», «руб») — ставим. Не названа — числа без значка валюты; поставить можно через «поменять».
- Картинка — **свой набор значков** (~20, в стиле значков привычек) + цвет по типу. Ничего не генерируем.
- Нейросеть — последнее средство, не больше одного запроса на цель, ответ запоминается для всех.

## Как узнаём (по порядку)

1. **Словарь без нейросети** (`shared/goalUnits.ts`, будет): ~200 основ слов RU+EN → тип, формы слова (одна / две / пять), значок, формат числа. Ищем в названии и рядом с числом. Число понимаем в виде «150к», «150 тыс», «1,5 млн», «полторы тысячи».
2. **Голос — в том же запросе.** Голосовой разбор и так идёт через модель: в его ответ добавляются поля `goal: {type, unit_forms, currency}` — лишнего запроса нет.
3. **Словарь не узнал → один запрос при создании**, ответ (тип, формы, значок) кладём в общую таблицу выученных единиц: «лиды» распознаются один раз на всех, запросов со временем меньше.
4. **По ходу дела.** Единица неизвестна — первый вклад «положила 5 тысяч рублей», «+12 км» её уточняет (разбор вклада голосом/в чате всё равно идёт).
5. Человек всегда может поправить подписью «поменять».
