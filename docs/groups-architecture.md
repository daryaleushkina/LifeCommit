# Группы: архитектура

Решения владелицы — допрос и круги 16–18 дизайна (01.10.2026), см. `docs/HANDOFF.md` («Что дальше», п. 4) и `docs/groups-goals.md`. Здесь — как это устроено в базе, API, боте и на экране.

## Сущности

```
groups ──< group_members >── users
   │
   ├──< group_items ──< group_item_marks      (кто когда сделал)
   │        └──< group_goal_entries            (вклады в общую цель)
   ├──< invites (code, expires_at)             (ссылки-приглашения)
   └── tg_chat_id                              (необязательный чат Telegram)
goal_units_learned                             (выученные нейросетью единицы, общие на всех)
```

- **groups** — переименованная `teams` из первой схемы (её никто не использовал). Поля: `title`, `kind` (family / sport / pair / friends / other — только для подсказок и значка), `color`, `owner_id`, `tg_chat_id` + `tg_chat_title` (привязанный чат, может не быть), `admins_only_edit` (дела заводят только админы), `rating_enabled`, `chat_digest`, `chat_reminders`, `archived_at`.
- **group_members** — переименованная `team_members`: `role` owner / admin / member, `joined_at`, `muted` (не присылать мне напоминания этой группы).
- **group_items** — одно «групповое дело» на все четыре режима «Кто делает»:
  - `mode`: `one` (кто-то один), `assign` (назначить), `goal` (общая цель), `event` (мероприятие);
  - расписание — как у дел: `day` (первый день / день разового), `time`, `duration_min`, `rrule`, `exdates`, `due_day` («до пятницы»);
  - назначение: `assignees bigint[]`, `all_members bool` («Все» — и будущие участники тоже), `rotate bool` (по очереди);
  - цель: `target numeric`, `unit jsonb` (`{type, forms[3], currency, icon}` или null), `goal_until date`;
  - `created_by`, `position`, `archived_at`.
- **group_item_marks** — отметка «сделано»: `(item_id, day, user_id)` + `done_at`. Для `one` и для назначенного по очереди закрывается одной отметкой на день: уникальный индекс `(item_id, day) where solo`.
- **group_goal_entries** — вклады: `item_id, user_id, amount, day, created_at`.
- **invites** — уже есть (`code`, `inviter_id`, `team_id` → `group_id`); добавляется `expires_at`.

Повторы считает тот же `shared/rrule.ts`, что и для дел из календаря: в базе одна строка, дни вычисляются.

## Кто делает: правила (одна функция `whoToday`)

| Режим | Кому показываем на «Сегодня» | Кто может отметить | Когда закрыто |
|---|---|---|---|
| `one` | всем участникам | любой | одна отметка за день (у всех «сделала Маша») |
| `assign`, один человек | ему | ему (остальные видят в группе) | его отметка |
| `assign`, несколько / «Все» | каждому из них | каждый своё | у каждого своя |
| `assign` + `rotate` | тому, чья очередь | очередному (или «Возьму я» — позже) | одна отметка за день |
| `goal` | всем — карточкой с прогрессом | вклад любой | цифра достигнута |
| `event` | тем, кто будет (assignees / all) | — (без галочки) | — |

Очередь: `assignees[n % assignees.length]`, где `n` — номер раза по расписанию с первого дня. Пропущенный день очередь не сдвигает (честно и предсказуемо).

**Карта:** отметка в `group_item_marks` — +1.0 к дню того, кто сделал (`user_heatmap` и `heatWithToday`). Мероприятия и вклады в цель на карту не влияют.

## Права

- Создать группу — любой; создатель — `owner`.
- Заводить и менять дела — все участники; если `admins_only_edit` — owner и admin.
- Отмечать — по таблице выше. Удалять группу — только owner.
- Всё проверяет Worker (RLS без политик, как везде).

## Как попадают в группу

1. **Ссылка** `t.me/LifeCommit_bot?startapp=g_<code>` (код в `invites`, 7 дней). Открыл — экран «Вступить» (16R).
2. **Бот в чате:** «Добавить бота в чат» (`t.me/LifeCommit_bot?startgroup=g_<code>`) → бот получает `/start g_<code>` в чате → привязывает чат к группе. Добавили бота в чат без ссылки (`my_chat_member`) → создаётся новая группа с названием чата.
3. Участник — только тот, кто открыл мини-апп (у нас есть его `users` строка). Нажал кнопку в чате без приложения → `answerCallbackQuery` с `url: t.me/LifeCommit_bot?startapp=g_<code>`.

## Бот в групповом чате

Бот видит в группе только команды, упоминания и ответы на свои сообщения (privacy mode) — этого хватает:
- **«Сегодня в группе»** — одно сообщение в день (закреплённое), кнопки `✓ <дело>` (callback `gm:<item>:<day>`); после отметки сообщение редактируется (кто и когда), новых сообщений не плодим.
- **Ответ на любое сообщение бота** текстом или голосом → разбор (тот же `voice.ts`) с группой по умолчанию = этот чат → предпросмотр «Добавить / Изменить / Отменить».
- **Вечерний итог** (cron, по поясу группы = поясу владельца): «Сделали 7 из 8», несделанное без имён; раз в неделю — карта картинкой (позже).
- **Напоминание** о несделанном с временем: «Возьму я / ✓ / Не напоминать».
Лимит Bot API в группе — ~20 сообщений в минуту: всё «склеиваем» редактированием одного сообщения.

## Календарь телефона

Дела и мероприятия группы со временем идут в календарь тех, кого касаются (`whoToday` на каждый день): мероприятие и «каждому» — всем, назначенное — назначенному, по очереди — очередному, «кто-то один» — всем, пока никто не сделал. Это проекция: у каждого участника своя связь `group_item_links (item_id, user_id, day?, external_href, etag)`, пишет её тот же `calsync.ts` через `Conn`. Этап 4.

## Голос

Тот же запрос к модели, что сейчас (`worker/voice.ts`), ответ расширяется: `group` (название группы из списка групп человека, который передаём в подсказке), `mode`, `assignees` (имена из участников), `rotate`, `time`, `repeat`, `target`, `unit`, `currency`, `event`. Лишних запросов нет. Подробно про единицы — `docs/groups-goals.md`.

## API (Worker)

```
GET    /api/groups                         мои группы + прогресс дня
POST   /api/groups                         создать {title, kind}
GET    /api/groups/:id                     группа, участники, дела на сегодня
PATCH  /api/groups/:id                     настройки (owner/admin)
DELETE /api/groups/:id                     удалить (owner) / выйти (POST /leave)
POST   /api/groups/:id/invite              новая ссылка-приглашение
GET    /api/invites/:code                  что за группа (экран «Вступить»)
POST   /api/invites/:code/join             вступить
POST   /api/groups/:id/items               новое дело (режим, люди, расписание, цель)
PATCH  /api/groups/:id/items/:item         поправить
DELETE /api/groups/:id/items/:item         удалить (в архив)
PUT    /api/groups/:id/items/:item/mark    {day, done}
POST   /api/groups/:id/items/:item/entries {amount}
```
`/api/today` дополняется блоками групп (одним SQL-вызовом, как сейчас `today_screen`).

## Экраны

- Вкладка **«Вместе»** (16A): список групп, «Новая группа» (16Q), приглашение, экран группы (дела / люди / карта).
- **«Сегодня»** (16B): блоки групп под личным.
- **Новое дело** (16H + 18): четыре плитки; «Назначить» — люди мультивыбором + «Все» + «По очереди».
- **Вступление по ссылке** (16R).

## Этапы

1. Группы, участники, приглашения и вступление, вкладка «Вместе», экран группы. ← сейчас
2. Групповые дела (`one`, `assign` с «Все» и очередью, `event`), отметки, блоки на «Сегодня», карта.
3. Бот в групповом чате: привязка, «Сегодня в группе» с кнопками, ответы голосом, итог дня, напоминания. Проверка в живом чате.
4. Общая цель (вклады, единицы), календарь телефона для групповых, голос с группами.
