# Что умеет каждый клиент

Правило — в `CLAUDE.md`, раздел «Платформы»: фича делается одним заходом во всех клиентах. Эта таблица — для того
времени, пока нативные догоняют мини-апп, и для того, чего на платформе не бывает по существу. Новая фича — строка
здесь в том же коммите.

Обозначения: **есть** · **ждёт** (раздела в клиенте ещё нет — придёт вместе с ним) · **нет на платформе** (с причиной).
Mac — это приложение из `apple/` (у старой оболочки `macos/` всё как в мини-аппе).
