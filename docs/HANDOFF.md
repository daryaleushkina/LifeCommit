## Что это

Мини-апп Telegram ([@LifeCommit_bot](https://t.me/LifeCommit_bot)): ежедневные дела, карта активности как в GitHub, в перспективе — сообщество (друзья, команды, челленджи). Важная аудитория — люди с СДВГ: минимум решений на экране, частичное выполнение засчитывается, никаких стриков и стыда.

Прямой конкурент — Challenger (https://t.me/ChallengerTgBot): дедлайны, ИИ-коуч, серии, соревнование. Наше отличие — бережность и совместные механики.

## Стек и устройство

- **Мини-апп:** React + Vite + TypeScript + `@tma.js/sdk-react` — `src/`.
- **Сервер:** один Cloudflare Worker на Hono — `worker/`: API (`api.ts`), проверка подписи Telegram (`auth.ts`), webhook бота (`bot.ts`), напоминания по cron раз в 15 минут (`cron.ts`), логический день (`day.ts`).
- **База:** Supabase Postgres. RLS включён на всех таблицах **без политик** — так задумано: доступ есть только у Worker'а по секретному ключу. Миграции — `supabase/migrations/`, применяются через Supabase MCP (и дублируются файлом в репозитории).
- **Общие типы** клиента и сервера — `shared/types.ts`.
- Мини-апп ходит только на свой Worker, не на `*.supabase.co` (риск блокировок в РФ).

Схема базы заложена под все этапы (подписки, команды, челленджи, жалобы), но используются пока `users`, `tasks`, `task_goals`, `task_logs`, `task_subtasks`, `task_templates`.

## Команды

```bash
pnpm dev          # http://localhost:5173 — мини-апп + Worker с подменённым Telegram
pnpm typecheck
pnpm test         # vitest: логический день, уровни карты, шаг кнопки, зачёт дел
pnpm build
pnpm bot:setup    # webhook, кнопка меню, команды и описания бота
```

**Деплой — при пуше в `main`, двумя путями:**
- **С Мака** (включён хук `scripts/hooks/pre-push`, один раз: `pnpm hooks:install`): перед пушем на самой машине идут typecheck, тесты, сборка и `wrangler deploy`; упало — пуш отменяется. Хук записывает SHA в переменную репозитория `LOCAL_DEPLOYED_SHA`, и GitHub Actions свою задачу пропускает — минуты не тратятся.
- **Из облачной разработки** (хука нет): деплоит GitHub Actions (`.github/workflows/deploy.yml`: typecheck, тесты, сборка, деплой). Одна минута на релиз.

`git push --no-verify` с Мака отдаёт деплой в Actions. Секреты репозитория: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`. Вручную: `pnpm run deploy`.

Секреты Worker'а лежат в Cloudflare: `TELEGRAM_BOT_TOKEN`, `SUPABASE_SECRET_KEY`, `TELEGRAM_WEBHOOK_SECRET`. Локально — `.env.local` и `.dev.vars` (в git не попадают).

Скриншоты экранов вне Telegram: `node .claude/skills/telegram-mini-app/scripts/screenshot.mjs --url http://localhost:5173/` (нужен `pnpm dev`).

## Что сделано (v0.1, личное ядро)

- Заставка: крупный знак 3×3 (клетки загораются по очереди) и название LifeCommit; данные грузятся, пока она на экране. Вариант с git-терминалом убран 30.09.2026: перегружен и непонятен тем, кто не знает git.
- «Чего я хочу?» — первый экран и первый шаг при добавлении привычки: три намерения с цветными плитками-иконками — «Делать регулярно» (`check`), «Считать что-то» (`count`), «Бросить» (`abstain`). Тап открывает редактор уже нужного вида; **выбора типа в редакторе нет**, вид у существующей привычки не меняется. Так решено после четырёх исследований 30.09.2026: приложения спрашивают либо намерение, либо способ отметки, но не смешивают их.
- «Сегодня»: дата, полоска карты за 22 недели (тап → профиль), карточки привычек в одну строку с круглыми кнопками отметки (`RoundBtn` в `src/components/TaskCard.tsx`): галочка у «делать»; карандаш (ввести число) и галочка (сделано целиком) плюс полоса прогресса у «считать»; крестик и галочка с вопросом «Получилось?» у «бросить» (после ответа вопрос сменяется счётом «N дней без этого»). Повторный тап по выбранной кнопке снимает отметку.
- Экран привычки (тап по названию, `src/screens/TaskDetail.tsx`): блок «сегодня» с теми же кнопками, ключевые числа, календарь месяца с числами (листается назад до месяца, когда привычка появилась), у «считать» — столбики за две недели с линией цели, у «бросить» — крупный счёт и «подряд сейчас / самый долгий период / раз было за месяц». Карандаш в шапке открывает редактор. История приходит одним запросом `GET /api/tasks/:id/history`, считается на клиенте чистыми функциями из `shared/stats.ts` (покрыты тестами).
- Три типа дел: **Количество / Да или нет / Отказ**. Частичное выполнение засчитывается. Тип «Лимит» («не больше N») убран 30.09.2026: ручной учёт «сколько плохого сделал» сложен, спроса не видно. В базе значение `limit` и его ветка в `log_score` оставлены — вернуть можно без миграции; сервер такие дела не создаёт.
- Редактор привычки: метка намерения, название (единственное обязательное поле), у «считать» — «Цель на день» с единицей, у «бросить» — «Последний раз»; «Повторять» (шторка: каждый день / по дням недели / несколько раз в неделю; у «бросить» строки нет) и «Кто видит». В интерфейсе везде слово «привычка», не «дело».
- «Отложить» дело (архив с возвратом) и экран «Отложенные». «Удалить» — прямо в редакторе дела, с подтверждением (стирает и историю).
- Профиль: вкладки «Месяц» (по умолчанию: небольшая сетка клеток одного месяца без чисел, листается назад на 11 месяцев) и «Год» (две полосы по полгода — клетки крупнее; оба вида лежат в одной клетке сетки, поэтому блок не меняет высоту при переключении), напоминание, конец дня, приватность профиля, тема (две иконки: солнце / луна; пока не выбирали — как в Telegram; хранится на устройстве в `localStorage`), язык (RU/EN), «Поддержать проект» → Tribute, удаление аккаунта.
- Бот: `/start` с кнопкой мини-аппа, напоминания утром/вечером. «Главный мини-апп» в BotFather включён — ссылки `t.me/LifeCommit_bot?startapp=…` работают (нужны для приглашений в v0.2).
- Светлая и тёмная тема: по теме Telegram или выбранная вручную в профиле.
- Системных выпадающих списков и полей даты/времени нет: всё выбирается в шторке снизу (`src/components/Picker.tsx`: `SelectRow`, `DateRow`, `TimeRow` — барабаны часов и минут). Напоминание — любое время с шагом 5 минут (cron ходит раз в 15 минут, так что приходит с задержкой до 15 минут); конец дня — любой час с 00:00 до 12:00 (в базе хранится только час).
- У каждого вида привычки своя цветная плитка с рисунком (`src/components/KindIcon.tsx`): зелёная, песочная, терракотовая — на экране выбора, в редакторе и на карточках в «Сегодня».

## Решения, которые нельзя терять

**Продукт**
- Логический день заканчивается в 04:00 по местному времени (настраивается).
- Карта: 4 уровня зелёного по **абсолютной** сумме выполненного за день (одно дело = до 1,0). Это выбор владелицы, не «% от плана».
- Цель стала легче — действует с завтра; сложнее — сразу. История целей хранится, прошлые дни не пересчитываются.
- Стриков нет. «Тяжёлого дня» (режима минимума) нет. Глобальной паузы нет — вместо неё дело откладывают в архив.
- «Бросить»: вопрос «Сегодня получилось?», ответ крестиком или галочкой; счётчик «N дней без этого» срыв не обнуляет. В редакторе можно указать «Последний раз» (`tasks.last_slip_on`): дни между этой датой и первым днём дела прибавляются к счёту (`cleanDaysBeforeStart` в `shared/types.ts`). На карту активности прошлые дни не попадают.
- У количества два действия: галочка (сделано целиком) и ввод числа (карандаш или тап по числу, только цифры). Кнопки «+N» нет; поле `tasks.step` и `autoStep` остались в коде сервера, но интерфейс их не использует.
- Бесплатно 5 личных дел, больше — по подписке; дела из челленджей в лимит не входят.
- Дела по умолчанию видны «Только мне».
- Слогана нет вообще.
- Донаты — через Tribute, не звёздами Telegram.

**Соцчасть (ещё не сделана, но решена)**
- Профиль открытый/закрытый, как в Инстаграме; подписки; приглашение по ссылке, поиск по @username, бот в групповом чате.
- «Команда» (не «кружок») = групповой чат с ботом, вступление кнопкой; карта команды и рейтинг по % своего плана.
- Реакции, «пнуть» раз в день, комментарии по настройкам; нужны блокировка и жалоба.
- Челленджи: своя цель, общий счётчик (простая шкала, **без сундука и уровней**), одинаковая цель, программа, парный квест недели, окно-доказательство, команда на команду. Публичные создаёт любой; автоскрытие после 3 жалоб + фильтр слов.

**Дизайн**
- Стиль A «Мягкий»: своя палитра (светлая и тёмная), шрифт Onest, токены — в начале `src/styles/app.css`.
- Правило экрана: одно главное действие, 3–4 блока, без легенд и подписей-пояснений; второстепенное — за тапом.
- Осознанное отступление от скилла `telegram-mini-app`: свои hex-цвета вместо `--tg-theme-*` (его `check.sh` на это ругается — так и должно быть).

## Грабли

- В `pnpm dev` React StrictMode запускает загрузку дважды: второй ответ может на секунду вернуть старое значение только что отмеченного дела. В проде загрузка одна.
- Отметить привычку можно с двух экранов, а ответы сервера приходят не по порядку, поэтому устаревание ответов отслеживает общий на приложение счётчик (`currentChange` / `bumpChange` в `src/useTaskLog.ts`): фоновое обновление, начатое до изменения, свой результат выбрасывает.
- **Локальная разработка пишет в боевую базу.** Тестовый пользователь из `src/telegram/mockEnv.ts` — `id = 1`; после проверок его нужно удалить (`DELETE /api/account`). На 30.09.2026 в базе его нет.
- В `.dev.vars` флаг `DEV_AUTH_BYPASS=1` разрешает подделанную подпись Telegram — только локально, в прод он попасть не должен.
- Бесплатный проект Supabase засыпает после 7 дней без активности. Сейчас его будит cron Worker'а (запрос раз в 15 минут); к запуску — тариф Pro.
- API-токен Cloudflare для автодеплоя один раз попал в вывод инструмента в сессии настройки. В файлах и git его нет; при желании — перевыпустить в Cloudflare и обновить секрет `CLOUDFLARE_API_TOKEN` в GitHub.
- Файлы в `.claude/skills/*` и `.mcp.json` правит сама владелица — не коммитить их без вопроса.
- В коммитах, PR и файлах не должно быть подписей про ИИ-ассистента.
