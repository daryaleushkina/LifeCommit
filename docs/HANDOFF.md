## Стек и устройство

- **Мини-апп:** React + Vite + TypeScript + `@tma.js/sdk-react` — `src/`.
- **Сервер:** один Cloudflare Worker на Hono — `worker/`: API (`api.ts`), проверка подписи Telegram (`auth.ts`), webhook бота (`bot.ts`), напоминания по cron раз в 15 минут (`cron.ts`), логический день (`day.ts`).
- **База:** Supabase Postgres. RLS включён на всех таблицах **без политик** — так задумано: доступ есть только у Worker'а по секретному ключу. Миграции — `supabase/migrations/`, применяются через Supabase MCP (и дублируются файлом в репозитории).
- **Общие типы** клиента и сервера — `shared/types.ts`.
- Мини-апп ходит только на свой Worker, не на `*.supabase.co` (риск блокировок в РФ).

Схема базы заложена под все этапы (подписки, команды, челленджи, жалобы), но используются пока `users`, `tasks`, `task_goals`, `task_logs`, `task_subtasks`, `task_templates`.

## Команды

```bash
pnpm dev          # http://localhost:5173 — мини-апп + Worker с подменённым Telegram
pnpm typecheck
pnpm test         # vitest: логический день, уровни карты, шаг кнопки, зачёт дел
pnpm build
pnpm bot:setup    # webhook, кнопка меню, команды и описания бота
```

**Деплой — при пуше в `main`, двумя путями:**
- **С Мака** (включён хук `scripts/hooks/pre-push`, один раз: `pnpm hooks:install`): перед пушем на самой машине идут typecheck, тесты, сборка и `wrangler deploy`; упало — пуш отменяется. Хук записывает SHA в переменную репозитория `LOCAL_DEPLOYED_SHA`, и GitHub Actions свою задачу пропускает — минуты не тратятся.
- **Из облачной разработки** (хука нет): деплоит GitHub Actions (`.github/workflows/deploy.yml`: typecheck, тесты, сборка, деплой). Одна минута на релиз.

`git push --no-verify` с Мака отдаёт деплой в Actions. Секреты репозитория: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`. Вручную: `pnpm run deploy`.

Секреты Worker'а лежат в Cloudflare: `TELEGRAM_BOT_TOKEN`, `SUPABASE_SECRET_KEY`, `TELEGRAM_WEBHOOK_SECRET`, `GEMINI_API_KEY`. Локально — `.env.local` и `.dev.vars` (в git не попадают).

Скриншоты экранов вне Telegram: `node .claude/skills/telegram-mini-app/scripts/screenshot.mjs --url http://localhost:5173/` (нужен `pnpm dev`).

## Решения, которые нельзя терять

**Продукт**
- Логический день заканчивается в 04:00 по местному времени (настраивается).
- Карта: 4 уровня зелёного по **абсолютной** сумме выполненного за день (одно дело = до 1,0). Это выбор владелицы, не «% от плана».
- Цель стала легче — действует с завтра; сложнее — сразу. История целей хранится, прошлые дни не пересчитываются.
- Стриков нет. «Тяжёлого дня» (режима минимума) нет. Глобальной паузы нет — вместо неё дело откладывают в архив.
- «Бросить»: вопрос «Сегодня получилось?», ответ крестиком или галочкой; счётчик «N дней без этого» срыв не обнуляет. В редакторе можно указать «Последний раз» (`tasks.last_slip_on`): дни между этой датой и первым днём дела прибавляются к счёту (`cleanDaysBeforeStart` в `shared/types.ts`). На карту активности прошлые дни не попадают.
- У количества два действия: галочка (сделано целиком) и ввод числа (карандаш или тап по числу, только цифры). Кнопки «+N» нет; поле `tasks.step` и `autoStep` остались в коде сервера, но интерфейс их не использует.
- **Лимитов нет** (01.10.2026, решение владелицы: «пусть пока для всех всё бесплатно, кроме аудио»): `FREE_TASK_LIMIT = null` в `shared/types.ts`; проверки на сервере, в боте и в интерфейсе остались — вернуть лимит можно одним числом (было 5). Дневной лимит голоса (20) остаётся.
- Дела по умолчанию видны «Только мне».
- Слогана нет вообще.
- Донаты — через Tribute, не звёздами Telegram.

**Соцчасть (ещё не сделана, но решена)**
- Профиль открытый/закрытый, как в Инстаграме; подписки; приглашение по ссылке, поиск по @username, бот в групповом чате.
- «Команда» (не «кружок») = групповой чат с ботом, вступление кнопкой; карта команды и рейтинг по % своего плана.
- Реакции, «пнуть» раз в день, комментарии по настройкам; нужны блокировка и жалоба.
- Челленджи: своя цель, общий счётчик (простая шкала, **без сундука и уровней**), одинаковая цель, программа, парный квест недели, окно-доказательство, команда на команду. Публичные создаёт любой; автоскрытие после 3 жалоб + фильтр слов.

**Дизайн**
- Стиль A «Мягкий»: своя палитра (светлая и тёмная), шрифт Onest, токены — в начале `src/styles/app.css`.
- Поверх — матовое стекло (30.09.2026, вариант 1 из круга 12 на холсте): карточки, карта активности, поля и нижняя панель полупрозрачные (`--glass`, `--glass-edge`, `--glass-blur`), под ними мягкие цветные пятна фона (`--glow` на `body`; тело не прокручивается, поэтому пятна стоят на месте). В тёмной теме — тёмное стекло со свечением. Шторки остаются сплошными ради читаемости.
- Числа — обычные (пропорциональные) цифры, **не `tabular-nums`**: в Onest моноширинная «1» даёт дыру («1 46»). Разряды — через `t.num()` (`Intl.NumberFormat`): 146, 1 146, 25 546.
- Правило экрана: одно главное действие, 3–4 блока, без легенд и подписей-пояснений; второстепенное — за тапом.
